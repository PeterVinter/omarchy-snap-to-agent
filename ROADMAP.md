# Roadmap

## v0.3

- History of the last 20 sends with send again and delete, and auto-delete of captures after the retention period (7 days by default; the setting exists, the cleanup does not yet).
- A settings view in the panel for `config.json`, and the hook switch.
- More languages (the panel follows Setup > Language already; only English is shipped).
- Bar menu on click, history and settings on right-click.

## Later

- Tested image flags per agent, so images can go as images instead of a file path.
- Reading terminal output in kitty (`kitten @ get-text`).
- An option to always start in `~` instead of `~/Work`.
- Highlight masked placeholders inside the context text.
